# SnowLand 官網內容搬遷

來源為 [SnowLand 客戶參考站](https://snowland.pages.dev/)。資料沿用現有的官網內容管理。包含首頁、四個官網校區、14 個雪場及既有細節分頁、26–27 官網展示價、攻略清單與文章正文、FAQ、冬夏攝影及作品、優惠、品牌介紹、招募、聯絡與頁尾。

先在執行正式 Django 的環境中確認目標資料庫與備份。使用包含這次匯入程式和範本的後端程式版本，由後端根目錄執行預覽。

```bash
python manage.py initialize_snowland_website --client snowland
```

預覽會列出新增、更新、保留及未對應的教練。核對結果後執行匯入。

```bash
python manage.py initialize_snowland_website --client snowland --apply
```

匯入限定 SnowLand，整批使用一個資料庫交易。既有文章正文、活動、教練介紹和排程狀態會保留。雪場資料或舊季展示價只有完整符合原始匯入範本時才更新。教練內容對應既有教練，未對應的代號列在預覽中。完成後重跑預覽可核對有無待新增資料。

本次無新增資料表。官網價目資料與結帳計價分開。正式站要一併發布本版前端圖片及野雪價目的直達路由。發布後可從首頁走校區、雪場、雪票／交通與攻略文章，再核對教練、冬夏攝影及作品頁。
