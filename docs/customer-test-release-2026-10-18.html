目前交付狀態

核心驗收通過；合併狀態以 GitHub PR 與 test commit 為準。完整後端基線 907 項：904 通過、3 略過；最後的付款歷史修正另跑 108 項相關回歸全部通過。28 支前端檢查及前端編譯通過。這版不會自動更新測試機，也不會自動清除或匯入客戶資料；不代表全站或第三方服務已全部驗收。

本輪實際點過的核心流程

  1. 訂課與付款狀態：選課、最低人數限制、程度分配、來源必填、價格試算、建立訂單、自動指派教練、稍後匯款、後五碼回報、後台確認付款、會員顯示同步。
  2. 會員訂單與課前資料：本人訂單詳情、取消課程歷史標示、課前連結定位、按訂課人數建立學員、姓名與年齡先存及重載；不會因此標成保險或聲明已完成。
  3. 教練課程：Email 登入、月曆選日期、定位對應課程、單／雙板月份時數。修正自訂課程類別導致分類時數為 0。
  4. 教練請假：超過天數阻擋、一般申請、總部批准／拒絕、拒絕原因必填、教練重新登入看到審核結果。
  5. 後台訂單聯絡與付款：聯絡人姓名、Email、電話、通訊軟體與訂購會員分開顯示；校區限制角色不會取得完整聯絡快照。多筆付款紀錄不再使儲存出現 500，只更新最新付款，保留舊紀錄。

以上使用本機假資料與測試銀行資訊，沒有實際匯款、刷卡或對客寄信。手機抽查為 390×844；不代表所有頁面已逐頁驗收。

更新測試機時

先確認下載的是這次交付的 test commit；備份並確認 SnowLand 資料庫連線後，由負責部署的人檢查 migration 計畫，再更新前後端及重啟原服務。不要在未確認連線與備份時直接修改 AWS 正式庫。
