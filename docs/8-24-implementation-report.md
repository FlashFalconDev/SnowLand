## 已完成

### 1. 組織與權限

- 校區與雪場改為多對多：多個校區可共用雪場，一個校區也可管理多個雪場。
- 總部可看全部；校區主管只看被指派校區；教練維持個人視角。
- 訂單、排課、薪資、通知、保險、評量與儀表板全部套用校區範圍。
- 舊管理員未設定新角色時仍可使用，避免升級後全部變成 403。
- 舊租戶只有雪場、沒有校區時，自動建立「主要校區」，不中斷官網與 LINE 訂課。

### 2. Console 與 UX

- 新增「校區與營運規則」：校區、雪場掛載、未付款保留、請假限制等集中設定。
- 主面板新增「各校區營運」及「客戶從哪裡來」統計，並依目前校區範圍切換。
- 新增獨立選單：自動通知、薪資結算、學習評量、保險與聲明書、代客訂課連結。
- 表單使用固定中文標籤、用途說明、空狀態與停用提示；窄螢幕改成單欄操作。
- 通知鈴移除假資料，改讀真實發送佇列。

### 3. 訂課、訂單與付款

- 訂課指定校區與雪場；只有一個校區時自動帶入，多個時讓客人選擇。
- 活動／行銷來源必填；LINE 與 AI 客服自動記錄來源。
- 員工可建立一次性、有到期時間的代客訂課連結；訂單保留建立人與校區。
- 課程模板支援按人／按組計價、最低開班人數、最低學員等級與教練資格。
- 訂單保留版本紀錄，可查看追加／追減差額。
- 取消退款依可設定階梯試算，再扣手續費；匯款退款要求銀行資料；狀態不可跳過核准。
- 多組收款帳戶可綁校區與雪場，付款頁自動選正確帳戶；未付款訂單到期後鎖定。

### 4. 人員、薪資、會員與課後

- 教練薪資支援時薪、指定費、介紹費、裝備協助與主管加給，避免多日課重複計費。
- 請假依校區規則檢查提前天數、連續天數及每日人數上限。
- 會員中心顯示會員等級、點數、舊生狀態、推薦碼，並可複製上次設定快速再訂。
- 課程完成後背景工作自動建立學員評量；後台可填教練評語、學習進度、完成雪道與媒體網址。
- 保險與聲明書提供缺件清單及一鍵完成，完成後自動離開待辦清單。
- 通知範本支援 Email、LINE、站內通知，並可設定校區、事件與提前天數。

### 5. 本地環境

- FFSystem 使用 `test_ffsystem` / 3307；SnowLand 使用獨立 `test_snowland` / 3308，兩套資料庫同時存在。
- 桌面啟動檔保留原本 FFSystem 全部服務，再加 SnowLand DB、Backend 8999、Frontend 5199、DB log。
- SnowLand backend 啟動時自動 migrate、建立最低可運行資料、處理一次到期／通知／評量工作。
- 最低資料指令可重複執行，不會重複新增；目前為 1 租戶、1 雪場、2 大類、2 類型、6 模板、6 時段。
- 本地免登入僅允許 DEBUG + 明確開關 + loopback，外部來源不會繞過登入。
