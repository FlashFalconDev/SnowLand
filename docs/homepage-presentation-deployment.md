# 首頁展示區塊接後台

入口：官網內容 → 首頁 → 首頁主視覺／首頁學校介紹／教練團隊區塊／首頁諮詢區塊。

- 主視覺：可改多行標題、中英文說明、靜音影片／圖片／純色背景、按鈕文字與連結。可直接貼YouTube或youtu.be影片網址，系統儲存為安全影片代號。
- 首頁學校介紹：保留原照片與版型，可改一般／粗體文字、新照片、展開段落及了解更多按鈕。不會連動覆寫獨立學校介紹內頁或課程價格。
- 清空按鈕連結即不顯示該按鈕。隱藏／到期的區塊不顯示，讀取失敗有重試，不回退成寫死的原文。
- 首頁原有照片使用可選的原圖參照，沒有新增重複大圖；也可填新的圖片網址或關閉圖片。
- 教練團隊區塊：標題、英文小標、說明、標題連結及上下架可設定；教練姓名、照片、內容與排序仍由「基本設定 → 教練管理」維護，不複製另一套名單。
- 首頁諮詢區塊：標題、說明、背景圖、按鈕文字與連結及上下架可設定；不影響聯絡表單收件設定。長文字不會被固定高度裁掉。

## 初始化（無新資料表／migration）

先確認環境與備份，再預覽缺少的原稿：

```cmd
python manage.py initialize_homepage_presentation --client snowland
```

確認後才補入：

```cmd
python manage.py initialize_homepage_presentation --client snowland --apply
```

只新增缺少的四區原稿，不覆寫既有設定、文字或上下架；已有主視覺／介紹時，只補缺少的教練與諮詢區。舊版page類型資料可保留並繼續編輯，前台亦相容；多筆重複／不相容類型會停止，不會部分寫入。未初始化的區塊不會回退顯示寫死文案。初始化本次只在127.0.0.1:3308/test_snowland執行，未操作測試機或正式庫。
