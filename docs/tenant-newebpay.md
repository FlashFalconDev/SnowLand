# SnowLand 藍新商店設定

租戶總部管理員（具收款帳戶與幣別權限）或平台最高管理員，可在 Console「財務 → 收款帳戶與幣別」新增本租戶的藍新商店。新增後先保留停用，核對環境後另按啟用。商店金鑰不會由後台讀回。

- 部署管理員先在伺服器秘密設定存放獨立的 Fernet 主金鑰 `SNOWLAND_NEWEBPAY_CREDENTIAL_KEY`。保留並安全備份：換掉它會使歷史憑證不可解密。此項不由租戶在 Console 設定。
- `SNOWLAND_NEWEBPAY_SANDBOX_ENABLED` 預設關閉。僅在隔離測試環境打開；測試商店與正式商店須分開，不共用金鑰或把測試交易寫進正式訂單。
- 台灣訂單預設匯款。具「修改與排課」權限的訂單操作人員，只有在已開啟商店且訂單可付款、金額正數、幣別為台幣時，才能逐單開放信用卡。校區唯讀角色仍不可修改。
- 產生付款表單後，該單保留原商店版本並停止改用匯款，避免兩邊重複付款。若客人未完成刷卡，需先由財務核對交易，不可直接人工標記退刷成功。更換或停用商店只影響新表單，舊表單回傳仍使用簽發時的憑證版本。
- 真實刷卡、查詢及退刷須另用核准的藍新測試商店驗證。現階段未提供主動呼叫藍新退刷的功能。
