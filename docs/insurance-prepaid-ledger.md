# 保險預付保費帳本

帳戶以租戶為單位，固定使用開帳幣別。財務在 Console「會員與課前資料 → 保險預付保費帳本」選擇「全部校區」後，可核對期初、儲值、分錄與月對帳。

## 設定與授權

在 Django Admin 的「模組設定」編輯該租戶的 booking 設定 JSON，保留其他鍵。

| 鍵 | 型別與預設 |
| --- | --- |
| `insurance_ledger_enabled` | 布林，預設關閉。只有 `true` 開啟。 |
| `insurance_ledger_currency` | 三碼英文字母，預設空。依專員帳戶設定，正式開帳後應維持同一幣別。 |
| `insurance_ledger_low_balance` | 非負 JSON 數字，預設空。帳戶餘額小於或等於門檻時，Console 顯示提示。 |

模組或租戶設定列停用時，使用上述預設值。扣款需同時持有 `insurance_records` 與 `insurance_ledger_deduct`。保險預設職位帶出扣款權限，行政小幫手仍可回報進度。請在「員工與權限」建立或編輯全校區總部職位，勾選 `insurance_ledger_finance` 後指派指定財務。總部預設全頁面及平台管理身分均需另行具備明確授權。

## 入帳與對帳

- 財務和專員先核對切帳點與實際可用期初餘額。期初與儲值須填正金額和核對憑證。首次登錄期初即建立帳戶。
- 啟用後輸入新正保費即扣款。不足會拒絕該次儲存，保費和進度保留原值。同幣金額相同、單改狀態、留空及零不扣。本功能啟用前留下的保費不補扣。
- 更正已扣保費時，承辦人填寫原因，系統同筆交易沖回原款與重扣。改期／換課清除保費時，舊扣款仍保留，財務核對憑證後才做沖正。其他需要財務確認的沖正也從帳本分錄操作。
- 月份依台北時區，以分錄登錄時間歸期。選取月份、核對期初與本期儲值、扣款和淨沖正，輸入專員對帳單的期末餘額。月結只能在月份結束後、雙方餘額一致時確認。確認後保留快照，可下載對帳數字。後續更正記入作業當月。
- 停用後，財務仍可查閱帳本與快照。曾有分錄的租戶禁止新增或變更正保費，也不能在投保作業直接清掉正保費。改期如會清掉已掛帳的正保費也會拒絕。從未開帳時，原保費輸入流程照常。

## 上線順序

1. 依 migration 手冊完成兩步確認後，先部署相容 schema、後端與 Console，帳本開關保持關閉。
2. 指派財務與扣款權限，填妥幣別及選用的低餘額門檻。財務和專員核對期初與切帳點。
3. 確認前後端版本一致後啟用帳本。財務登錄期初後才可扣款。
4. 需暫停時先關開關，保留 schema、分錄與停寫保護。已有分錄的環境若須退回舊版，先限制受影響租戶的保費、會清保費的改期與測試訂單標記寫入。反向 migration 會刪除帳本，適合隔離空庫的演練。
