# 官網校區導覽（客戶簡報第63頁）

後台入口：官網內容 → 滑雪課程 → 官網校區導覽。

- 名稱、副標題、說明、排序、上下架及所屬雪場均由後台管理；網址代號建立後固定，以免舊連結失效。
- 同一雪場可出現在多個官網分組，雪場卡片／圖片／標籤仍讀既有官網雪場列表，沒有複製第二份內容。
- 這是官網展示分組，不會更改基本設定中的營運校區、員工權限、排班或訂單歸屬。
- 校區下架／到期後不顯示於選單，直達連結顯示尚未開放；未發布的雪場不會顯示。讀取失敗有重試，不顯示假資料。

## 原稿初始化

沒有新增資料表或migration。部署前確認對應程式版本與資料庫備份，先預覽：

```cmd
python manage.py initialize_course_areas --client snowland
```

確認後才執行：

```cmd
python manage.py initialize_course_areas --client snowland --apply
```

只補缺少的客戶4區原稿；保留既有名稱、分組、上下架與排序。重複代號／錯誤類型會停止，不部分寫入。新增原稿後管理者可自行調整，不需修改前端程式。

本次只在127.0.0.1:3308/test_snowland初始化；沒有操作測試機、AWS、正式庫或部署。
