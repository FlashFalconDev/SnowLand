先怎麼測

Jim 更新測試機、執行 SnowLand 資料庫遷移並確認測試網址後，請用下列角色逐項操作。合併到 Git test 不會自動更新測試機。以下路徑接在測試機網址後面；不要用本機 127.0.0.1 網址分享給客戶。

  1. 會員：/snowland/membership 登入、查看訂單與課前資料。
  2. 前台：/snowland/ 查看雪場及課程內容，再到 /snowland/booking 試訂課。
  3. 總部／校區角色：/snowland/console 依角色檢查校區、課程、訂單、排課與付款資訊的可見範圍。
  4. 教練：登入後檢查待確認課程、接課、我的課程、月曆與時數。

請只用標記為測試的帳號與訂單；不做真實付款、不用真實客戶個資。若要測法律簽署，須由 SnowLand 指定測試者自行閱讀並操作。

項目請提供的格式／內容用途
測試人員與角色每個角色一個測試用 Email：總部、校區經理、校長、教練、會員；請註明所屬校區。不需傳密碼，由系統建立或重設。讓客戶驗證自己的權限與畫面。
正式法律內容已收到聲明書／保險條款草稿。法務定稿後請提供版本日期、完整文字、必填保險欄位與簽署方式；可用 Google Doc 或 Word。正式上線文件版本，不阻擋目前非正式測試。

既有訂單已收到本季訂單表，不用重寄。只需確認不明欄位、重複單、退款／改期單與會員 Email 對應；我們整理例外清單後再逐項核對。11/15 前匯入與會員綁定。
官方社群授權若要同步 SnowLand 官方 Instagram，請以 Meta Business 後台將該 IG／Facebook Page 的必要權限授予整合帳號；不傳帳密。Google／LINE 若由 SnowLand 持有設定，請指定管理員協助授權測試網域與回呼網址。真實第三方登入與社群同步；既有光隼 Facebook 權限不代表已有 SnowLand 官方 IG 權限。
金流與通知驗收確認測試用銀行帳戶／幣別、付款方式規則與通知收件測試地址。正式憑證只透過安全管道由持有人設定，不貼在簡報或訊息。測試實際付款、回呼及 Email／LINE 發送。
