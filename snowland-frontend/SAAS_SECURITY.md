# 🔒 SaaS 多租戶安全最佳實踐

## ⚠️ 重要：不要洩漏客戶名單！

作為 SaaS 服務供應商，**絕對不能讓公開頁面顯示所有客戶列表**！

---

## ❌ 錯誤做法（已修正）

### 問題：首頁顯示所有客戶
```
http://yourdomain.com/

🏔️ Snowland 多租戶系統
請選擇您的滑雪學校

┌─────────────────────────┐
│ 雪域創遊 (snowland)      │  ← ❌ 洩漏客戶名單！
│ 測試滑雪學校 (testski)   │  ← ❌ 商業機密外洩！
└─────────────────────────┘
```

**後果**：
- ❌ 洩漏了你的客戶名單
- ❌ 競爭對手可以看到你有哪些客戶
- ❌ 客戶可能不希望被公開
- ❌ 安全風險（可以嘗試猜測其他客戶的代碼）

---

## ✅ 正確做法（已實現）

### 方案 1：要求輸入客戶代碼（當前實現）

**首頁顯示**：
```
http://yourdomain.com/

滑雪預約系統
請輸入您的客戶代碼以繼續

┌─────────────────────────┐
│ 客戶代碼：[輸入框]       │
│ [繼續按鈕]              │
│                         │
│ 提示：客戶代碼由您的     │
│ 業務負責人提供           │
└─────────────────────────┘
```

**優點**：
- ✅ 不洩漏任何客戶資訊
- ✅ 只有知道代碼的人才能訪問
- ✅ 簡單易用

**缺點**：
- ⚠️ 用戶需要記住或查找客戶代碼

---

### 方案 2：直接提供完整 URL（推薦）

**直接給客戶完整的 URL**：
```
雪域創遊：http://yourdomain.com/snowland
測試學校：http://yourdomain.com/testski
```

**首頁** (`http://yourdomain.com/`) 顯示：
```
🏔️ Snowland SaaS 滑雪預約系統

為滑雪學校提供專業的預約管理服務

[了解更多] [聯繫我們]
```

**優點**：
- ✅ 客戶可以直接加入書籤
- ✅ 不需要輸入代碼
- ✅ 首頁可以作為公司官網

---

### 方案 3：子域名（最專業）

```
雪域創遊：http://snowland.yourdomain.com
測試學校：http://testski.yourdomain.com
```

**優點**：
- ✅ 每個客戶有獨立的域名
- ✅ 更專業
- ✅ 可以設定獨立的 SSL 證書
- ✅ 完全隔離

**缺點**：
- ⚠️ 需要設定 DNS wildcard
- ⚠️ 需要修改 middleware 解析子域名

---

## 🛡️ 安全建議

### 1. **首頁不顯示客戶列表**
- ✅ 首頁應該是公司官網或輸入頁面
- ❌ 不要列出所有客戶

### 2. **客戶代碼保密**
- 客戶代碼應該只有：
  - ✅ 業務負責人知道
  - ✅ 客戶自己知道
  - ❌ 不要公開在網站上

### 3. **訪問控制**
- ✅ 後端必須驗證 client_code 是否存在
- ✅ 無效的 client_code 返回 404
- ❌ 不要返回「該客戶不存在」（會洩漏資訊）

### 4. **給客戶的資訊**
當你將系統交付給客戶時，提供：
```
【雪域創遊滑雪預約系統 - 訪問資訊】

系統網址：http://yourdomain.com/snowland
（請加入書籤以便快速訪問）

登入方式：使用 Google 帳號登入

如有問題，請聯繫：
業務負責人：張三
Email: sales@yourdomain.com
```

## 💡 最佳實踐建議

### 給新客戶的設定流程

1. **創建客戶**（後端 Django Admin）
   ```python
   Client.objects.create(
       name='新滑雪學校',
       internal_code='newski',  # 隨機生成或客戶選擇
       is_active=True
   )
   ```

2. **生成訪問資訊**
   ```
   客戶名稱：新滑雪學校
   客戶代碼：newski
   訪問網址：http://yourdomain.com/newski
   ```

3. **發送給客戶**
   - 📧 Email 通知
   - 📄 提供操作手冊
   - 🔗 提供快速訪問連結

4. **不要公開**
   - ❌ 不要把 client_code 放在公開網站
   - ❌ 不要在首頁列出客戶
   - ✅ 只告訴客戶自己的代碼

---

## 🎯 總結

### 作為 SaaS 供應商，你應該：

✅ **要做的**：
- 每個客戶有獨立的訪問 URL
- 客戶代碼保密（只有客戶自己知道）
- 首頁不顯示客戶列表
- 提供清晰的訪問說明給客戶

❌ **不要做的**：
- 公開顯示所有客戶名單
- 讓客戶可以看到其他客戶
- 在公開頁面洩漏商業機密

---
