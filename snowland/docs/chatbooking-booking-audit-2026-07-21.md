# SnowLand AI 客服訂課健檢

健檢日期：2026-07-21  
範圍：LINE AI 客服、報價、訂單、自動排課、付款防線與正式課程設定。

## 執行方式

- 隔離記憶體資料庫：建立測試租戶、課程、價格、時段與教練，不會留下正式訂單。
- 真實 OpenAI：在隔離資料庫中送出「確認下單」，驗證模型實際呼叫確認工具並建立、排定測試訂單。
- 正式 SnowLand 資料庫：僅進行讀取與權威算價檢查，沒有修改日期、價格、教練或訂單。

## 已通過

- 選課資料驗證、報價與價格防竄改。
- 客人未明確確認時禁止下單。
- 報價後以新訊息明確確認才能建立訂單。
- 重複確認使用相同 idempotency key 時只建立一張訂單。
- 有合格教練時自動排課成功，訂單才開放付款。
- 無合格教練時保留訂單為排課失敗，並阻擋付款。
- 排課成功後可登記匯款帳號後五碼。
- 真實 OpenAI 確認下單測試通過。
- 客服模組 41 項測試通過，其中真實 OpenAI 測試平時預設略過，已另行手動執行並通過。

## 高優先問題

### 日期設定

- ID 25：單板半天基礎滑行，課程開始日為 2026-06-01，因此 7 月也被列為可預約。
- ID 2：單板全天基礎滑行，課程開始日為 2026-06-01，因此 7 月也被列為可預約。
- ID 23、37、38：課程開始日在課程結束日之後。
- ID 38、43：預約開放日在預約截止日之後。
- ID 17、18、31：四個日期欄位皆未設定，系統會視為沒有日期限制。

### 無法完成報價

116 組方案與雪場組合中有 52 組沒有有效定價。客人仍可能先看到或選到這些方案，但建立報價時才失敗。

### 無法自動排課

32 組方案與雪場組合在中文、初學者條件下找不到可行教練。若客人選到這些組合，訂單會建立為排課失敗並禁止付款，需真人客服介入。

### 方案不完整

- ID 20、42、43、44：沒有啟用時段。
- ID 30：沒有綁定雪場。
- ID 17、18：方案名稱標示 2H，但 `duration_hours` 為 3。

## 建議處理順序

1. 修正日期前後顛倒、6 月滑雪課與完全未設定日期的方案。
2. 補齊 52 組缺少的價格，或取消不應開放的方案與雪場綁定。
3. 補齊 4 個方案時段及 ID 30 的雪場。
